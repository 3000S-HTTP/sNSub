# =============================================================================
#  sources.txt  --  where the node lists come from. One URL per line.
# =============================================================================
#
#  * To ADD a source    : append a new line with the URL.
#  * To DISABLE a source: put a '#' in front of it (or delete the line).
#  * The format is auto-detected: plain text lists AND base64 subscription
#    bodies both work, so most public "sub" links can be dropped in as-is.
#  * Every source is optional. If one is unreachable the build continues and
#    simply reports it as [DEAD]; it only fails if *all* sources are dead.
#  * Nodes from every source are merged, de-duplicated, grouped by protocol
#    and re-encoded. Adding a low quality source cannot crash the build.
#
#  Commit your edit and the scheduled GitHub Action picks it up on the next
#  run -- no code change needed.
# =============================================================================
